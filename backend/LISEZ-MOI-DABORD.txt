🚀 DÉMARRAGE ULTRA-RAPIDE (5 minutes)
══════════════════════════════════════════════════════════════

1. Installer Node.js (si pas déjà installé)
   👉 https://nodejs.org
   
2. Installer MongoDB (si pas déjà installé)
   👉 https://www.mongodb.com/try/download/community
   
3. Dans ce dossier, ouvrir un terminal et taper:
   
   npm install
   
4. Copier le fichier de configuration:
   
   Windows: copy .env.example .env
   Mac/Linux: cp .env.example .env
   
5. Démarrer MongoDB:
   
   Windows: net start MongoDB
   Mac: brew services start mongodb-community
   Linux: sudo systemctl start mongod
   
6. Lancer le serveur:
   
   npm run dev
   
7. Tester dans votre navigateur:
   
   👉 http://localhost:5000/health
   
   Vous devriez voir du JSON avec "success: true"


❌ ERREUR IDENTIFIÉE DANS LE FRONTEND
══════════════════════════════════════════════════════════════

PROBLÈME:
Le frontend pointe vers http://localhost:3000/api
Mais le backend tourne sur http://localhost:5000/api

SOLUTION:
1. Ouvrir: frontend/js/main.js
2. Ligne 5: Changer de "3000" à "5000"
3. Sauvegarder

Détails complets: GUIDE-CORRECTION-FRONTEND.md

🔧 CONFIGURATION MINIMALE
══════════════════════════════════════════════════════════════

Dans le fichier .env, vous DEVEZ configurer:

1. JWT_SECRET (pour la sécurité)
   Changez la valeur par défaut!
   
2. MONGO_URI (base de données)
   Par défaut: mongodb://localhost:27017/chu_yaounde
   En production: utilisez MongoDB Atlas (gratuit)
   
3. ALLOWED_ORIGINS (sécurité CORS)
   Ajoutez l'URL de votre frontend
   Exemple: http://localhost:8080

Le reste est OPTIONNEL pour commencer.
